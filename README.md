# Notes book на Django

Веб-приложение, объединяющее личный приватный блокнот и публичную ленту для обмена идеями. Проект имеет как классический веб-интерфейс (на шаблонах), так и REST API.

## Технологический стек
- Backend: Python, Django, Django REST Framework (DRF)
- База данных: PostgreSQL
- Аутентификация: Сессии (для веба) и проверка прав доступа (для API)

## Публичная лента (форум)
- Просмотр общих записей — доступна всем посетителям.
- Публиковать записи могут только авторизованные пользователи.
- API: GET /api/notes/, POST /api/notes/

## Личный кабинет (приватный блокнот)
- Создание, просмотр, редактирование и удаление личных заметок.
- Привязка тегов к заметкам.
- Поиск и постраничная навигация.
- API: GET/POST /api/home/, GET/PATCH/DELETE /api/home/<id>/

## Общий функционал
- Регистрация и авторизация пользователей.
- Изоляция данных: личные заметки видны только их владельцу.
- Защита прав доступа: пользователь не может редактировать или удалять чужие записи.

## Установка
1. Склонируйте репозиторий
2. Создайте виртуальное окружение: 'python -m venv .venv'
3. Активируйте его '.venv\Script\activate'
4. Установите зависимостей: 'pip install -r requirements.txt'
5. Установите PostgreSQL и создайте базу 'notes_book'
6. Настройте 'setting.py'
7. Выполните миграции: 'python manage.py migrate'
8. Запустите 'python manage.py runserver'
