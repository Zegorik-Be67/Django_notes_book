# Notes book на Django

Простое веб-приложение для управления личными записями и общения между пользователями. Каждый пользователь может общаться с другими пользователями на главной странице, либо в личном кабинете добавить записи, которые доступны только ему.
## Функционал
- Регистрация и авторизация пользователей
- Общедоступный чат
- Добавление, редактирование и удаление задач в личном кабинете
- Личный список задач для кадого пользователя (изоляция данных)

## Установка
1. Склонируйте репозиторий
2. Создайте виртуальное окружение: 'python -m venv .venv'
3. Активируйте его '.venv\Script\activate'
4. Установите зависимостей: 'pip install -r requirements.txt'
5. Установите PostgreSQL и создайте базу 'notes_book'
6. Настройте 'setting.py'
7. Выполните миграции: 'python manage.py migrate'
8. Запустите 'python manage.py runserver'
